# IBM Plex Mono

Locally served IBM Plex Mono webfonts from IBM's `plex` project:
https://github.com/IBM/plex/tree/master/packages/plex-mono/fonts/complete/woff2

Regular, Medium and Bold upright weights. Distributed under the SIL Open Font
License in `OFL.txt`. Fonts load with `font-display: swap`; no third-party font
requests are made by the application.
